# Prison Handler - Android Game

A strategic simulation game where you build and manage a prison facility. Similar to Prison Architect, manage resources, handle inmates, and keep your prison running smoothly.

## Features
- Build and manage prison structures
- Manage inmates and staff
- Resource management (food, money, utilities)
- Real-time simulation
- Top-down view gameplay
- Save/Load functionality

## Project Structure
```
Prison-Handler/
├── project/               # Godot project files
├── scenes/               # Game scenes
├── scripts/              # GDScript files
├── assets/               # Sprites, sounds, textures
├── data/                 # Game data files
└── README.md
```

## Tech Stack
- **Engine**: Godot 4.x
- **Language**: GDScript
- **Target Platform**: Android

## Getting Started

### Prerequisites
- Godot Engine 4.x installed
- Android SDK (for Android export)

### Setup
1. Clone the repository
2. Open `project/project.godot` in Godot Engine
3. Run the project locally first
4. Export to Android when ready

## Game Mechanics

### Building System
- Place rooms and facilities
- Connect utilities (water, electricity)
- Manage zones (prison, staff, storage)

### Inmate Management
- Assign inmates to cells
- Monitor behavior and status
- Handle discipline and escapes

### Resource Management
- Food production and distribution
- Money management
- Utility systems
